AI 연결

모든 방이 같은 제공자를 사용합니다. 변경하면 기존 방은 유지되고 새 키가 필요합니다.

OpenAI에서 키 발급하기 · 추천 실행 시 본인 계정에 요금이 발생할 수 있습니다.

키와 웹훅은 OS 자격 증명 저장소에, 프로필은 이 기기에 저장됩니다. 추천 실행 시 내 키로 프로필을 선택한 AI 제공자에게 전달합니다. 기밀·민감 정보는 넣지 마세요.

기회 선택부터 예약까지, 이 방에만 적용할 설정입니다.

1 어떤 기회를 찾을까요?

알림 틀별 용도 보기

공통 프로필은 항상 사용하며, 방 하나에 쓰는 자료는 합계 60,000자 이내여야 합니다. 직접 선택에서 아무 자료도 고르지 않으면 공통 프로필만 사용합니다.

2 어디로 받을까요?

채널에서 웹훅 만들기

Discord · 서버 설정 → 연동 → 웹후크 → 새 웹후크 → 채널 선택 → URL 복사.

Slack · 앱에서 Incoming Webhooks 활성화 → Add New Webhook to Workspace → 채널 선택 → URL 복사. 관리자 승인이 필요할 수 있습니다.

3 언제 받을까요?
실행 요일

켜면 선택한 요일에 내 API 키로 검색·추천하고 채널에 발송합니다. 꺼 두고 먼저 테스트해도 됩니다.
