기회 선택부터 예약까지, 이 방에만 적용할 설정입니다.

1 어떤 기회를 찾을까요?

알림 틀별 용도 보기

자료를 고르지 않으면 위에서 허용한 공개 링크와 기존 자기소개만 사용합니다. 추천에 쓸 본문은 모두 합해 60,000자까지입니다.

2 어디로 받을까요?

채널에서 웹훅 만들기

Discord · 서버 설정 → 연동 → 웹후크 → 새 웹후크 → 채널 선택 → URL 복사.

Slack · 앱에서 Incoming Webhooks 활성화 → Add New Webhook to Workspace → 채널 선택 → URL 복사. 관리자 승인이 필요할 수 있습니다.

3 언제 받을까요?
실행 요일

켜면 선택한 요일에 내 API 키로 검색·추천하고 채널에 발송합니다. PC가 켜져 있고 jobevent가 실행 중일 때만 보내며, 꺼져 있던 동안 놓친 회차는 다음 실행 때 한 번만 보냅니다. 꺼 두고 먼저 테스트해도 됩니다.
